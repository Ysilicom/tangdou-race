# 糖豆闯关

单人 3D 障碍闯关小游戏（浏览器即可玩），灵感来自派对闯关类玩法，原创作品。

## 在线游玩

GitHub Pages：**<https://ysilicom.github.io/tangdou-race/>**

（若打不开，请到仓库 Settings → Pages，将 Source 设为 `main` / root。）

## 本地运行

无需构建。用任意静态服务器打开根目录，或直接双击 `index.html`（部分浏览器对模块/CDN有限制时建议用本地服务器）：

```bash
# 例如
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 操作说明

| 平台 | 操作 |
|------|------|
| 键盘 | WASD / 方向键移动，空格跳跃 |
| 手机 | 左侧虚拟摇杆移动，右侧「跳」按钮 |

## 关卡结构

1. **起点** — 宽阔出发平台  
2. **旋转棒** — 水平旋转长杆，撞到会被弹飞  
3. **吊锤桥** — 窄桥 + 钟摆大锤  
4. **移动平台** — 左右移动的踏板与会掉落的六边形砖  
5. **终点** — 皇冠领奖台，冲上去过关  

## 技术

- Three.js（CDN r150）
- 自研简易物理（重力、落地、击退）
- 纯静态：`index.html` + `style.css` + `game.js`
